## Interpretation and limits

- MODIS is used as the reference scale for continuity with the long MODIS record; it is not ground truth. Its own omission and commission errors remain in the target.
- The calibration maps a VIIRS measurement to an expected MODIS-scale measurement for the same cell and overpass. It does not make the sensors equivalent and does not recover fires that neither sensor detected.
- With unit_set = 'matched', the model is conditional on both sensors reporting a detection; it does not describe cells where only one sensor detected fire.
- Coefficients are empirical for this AOI, period, filters and sensor pair. Re-fit before applying them elsewhere.
- Standard errors assume independent units; neighbouring cells and successive days are correlated, so the intervals are optimistic.
- These are results of an implemented method on the imported data. They are not an independent scientific validation; that would need comparison with coverage-aware reference data and peer review.

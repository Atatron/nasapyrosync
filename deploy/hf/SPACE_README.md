# PyroSync (read-only demo)

Independent hackathon prototype using NASA FIRMS data. Not an official NASA application.
This Space runs the read-only demo with the full Indonesian archive (MODIS Terra and Aqua 2000–2026, VIIRS S-NPP, NOAA-20 and NOAA-21).
Importing data and the FIRMS refresh are switched off here; they work in the local version.
